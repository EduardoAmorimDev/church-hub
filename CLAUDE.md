## Repository Constitution (always binding)

`docs/constitution.md` governs every change made to this repository by an AI
agent, not only work started from a spec. Read it before any code edit, refactor,
or fix, even for small ad-hoc requests. It extends the general constitution at
`~/Documents/docs/constitution.md`; read both. It is the normative version of
`AGENTS.md` and wins on any conflict. If the constitution and a more specific
instruction conflict, flag the conflict instead of silently picking one.

The Claude Code configuration (settings, hooks, skills) is global, in `~/.claude/`.
